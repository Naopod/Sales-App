Tests Statistiques

Tests de Normalité (Shapiro-Wilk)
{{ results_month.tests_normalite|safe }} * p-value < 0.05 : distribution non normale
Interprétation : Le test de Shapiro-Wilk évalue si les données suivent une distribution normale. Si p-value < 0.05, les données ne sont pas normalement distribuées, ce qui est fréquent pour les données de ventes (présence de valeurs extrêmes, pics saisonniers).
Valeurs Aberrantes (IQR)
{{ results_month.valeurs_aberrantes|safe }} * Outliers = valeurs hors [Q1-1.5×IQR, Q3+1.5×IQR]
Interprétation : Les valeurs aberrantes sont des observations exceptionnelles qui s'écartent fortement de la tendance générale. Elles peuvent représenter des commandes exceptionnelles (très grandes ou très petites) qui méritent une attention particulière.
