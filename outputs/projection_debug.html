Projection de portefeuille — STL + HistGBM Quantile Ensemble

STL + HistGBM Quantile Ensemble
Moteur de Projection
Le moteur projette le chiffre d'affaires mensuel de chaque client aux horizons 3, 6 et 12 mois, puis agrège les projections en scénarios portefeuille.
1 Feature Engineering

Pour chaque (client, mois), 25+ features : lags CA (1,2,3,6,12), moyennes glissantes, écarts-types, pentes de tendance, quantité, fréquence, prix unitaire, saisonnalité (sin/cos), score comportemental.

2 Global HistGBM Quantile

Un modèle HistGradientBoostingRegressor (sklearn) entraîné sur tous les clients simultanément — cross-learning. 3 modèles quantiles : q10 (pessimiste), q50 (base), q90 (optimiste).

3 STL Trend Extrapolation

Pour les clients avec ≥ 18 mois d'historique : décomposition STL (Seasonal-Trend via LOESS) + extrapolation linéaire de la tendance.

4 Ensemble 60/40

Blend pondéré GBM (60%) + STL (40%) quand STL est disponible. Si l'historique est trop court pour STL, 100% GBM.

5 P(churn) — Probabilité d'attrition

Score combiné : risque comportemental (55%) + recency (max 25%) + pente de tendance 6M (max 20%). Clients > 50% = alerte churn.
